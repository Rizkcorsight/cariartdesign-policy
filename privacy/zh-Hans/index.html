Android 技术数据发送给 Google

Android 使用 Google ML Kit 进行设备上的人脸检测。其 SDK 将以下信息传输给 Google：安装标识符、设备和应用程序信息以及技术使用情况、性能和错误指标。 Google 使用这些来进行诊断、使用情况分析、维护和改进其 API 以及检测滥用情况。这些指标不包含您的照片或面部处理结果。 ML Kit 通过 HTTPS 发送此信息。谷歌根据自己的隐私政策处理它；它不仅限于按照我们的指示行事。
